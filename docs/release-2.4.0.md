# Videria 2.4.0 — repositorio único de proyectos

- `HansNieto/videria` contiene únicamente la aplicación, sus skills y documentación.
- `HansNieto/videos` contiene todos los proyectos editables, sin originales, cachés ni renders.
- La pantalla inicial puede clonar la raíz de `videos` y registrar todos los proyectos internos.
- “Recibir cambios” opera sobre la raíz Git compartida aunque se pulse desde un proyecto.
- Las secuencias PNG de motion graphics y los proxies se guardan con rutas portables.

Instalación: descarga `Videria-2.4.0-Windows-x64.zip` desde Releases, extrae todo
y ejecuta `Instalar-Videria.cmd`. Para obtener los proyectos, pega
`https://github.com/HansNieto/videos` en “Descargar proyectos de GitHub”.
