Preparación de una sola vez

Instala herramientas

Necesitas Python, Git, ffmpeg y GitHub CLI.

pip install flask numpy pillow
gh auth login

Clona e instala Videria

git clone https://github.com/HansNieto/videria.git
cd videria
.\instalar.ps1

Acepta la invitación

El propietario debe agregarte como colaborador de cada repositorio privado.

Recibir un proyecto

La primera vez, clona la URL que te envíen:

cd C:\Videria\revisiones
git clone URL-DEL-REPOSITORIO
cd videria-V021-precio-servicio

Si ya lo habías descargado, no lo clones otra vez:

cd C:\Videria\revisiones\videria-V021-precio-servicio
git status
git pull
Antes de editar: git status debe estar limpio y git pull debe terminar correctamente.
$VCUT = "$env:USERPROFILE\.claude\skills\video-cut\scripts\vcut.py"
python $VCUT studio --project .

Lista de revisión creativa

Si añades imágenes, música, sonidos u overlays, impórtalos desde el Studio y verifica que aparezcan dentro de assets/. Una ruta a tu Escritorio no funcionará en la máquina del propietario.

Entregar la revisión

Cierra el Studio después de guardar y ejecuta:

git status
git add -A
git commit -m "Revisión creativa lista para render"
git pull --rebase
git push
Cuando git push termina sin errores, la revisión está entregada. El propietario recibe un aviso y renderiza desde sus originales.

No crees archivos llamados final-final. El commit de Git ya identifica la versión entregada.

Cuando actualicemos la app

Los proyectos no se reinstalan. Solo actualizas la carpeta de Videria y vuelves a copiar sus skills:

cd C:\ruta\a\videria
git status
git pull
.\instalar.ps1

Cierra los Studio abiertos y vuelve a ejecutarlos. Si el propietario avisa que un proyecto requiere una versión nueva, actualiza antes de tocarlo.

Si git status dentro de la app muestra archivos modificados, no hagas pull a ciegas. Envía una captura al propietario.
