Preparación de una sola vez

Instala dependencias

Necesitas Python, ffmpeg, ffprobe, Git y GitHub CLI.

pip install flask numpy pillow faster-whisper
gh auth login

Instala Videria

cd C:\Users\Hans\Documents\videria2.0\videria
.\instalar.ps1

Define la nomenclatura

Usa V021-tema-corto, V022-tema-corto… El número evita perder el orden aunque cambie el título.

Qué hacer con cada vídeo

La opción fácil: pedírselo a Codex

No necesitas abrir PowerShell. Escribe este mensaje en una tarea de Codex, cambiando solamente el número de vídeo:

Preedita el video de esta carpeta:
C:\Users\Hans\Documents\videria2.0\videria\videos\video17

Usa la plantilla tiktok, no renderices todavía y abre el Studio al terminar.
Para la carpeta que aparece en tu captura, ese mensaje es suficiente. Codex ejecutará el proceso y te irá mostrando el progreso.

La opción manual: ejecutar el comando tú mismo

cd C:\Users\Hans\Documents\videria2.0\videria
.\nuevo-video.ps1 ".\videos\video17" -Nombre "video17" -Plantilla tiktok
El procesamiento crea videos\video17-proyecto al lado de videos\video17. La primera carpeta es la edición; la segunda conserva los originales.

Subir el proyecto para tu amigo

$VCUT = "$env:USERPROFILE\.claude\skills\video-cut\scripts\vcut.py"
python $VCUT repo init `
  --project "C:\Users\Hans\Documents\videria2.0\videria\videos\video17-proyecto" `
  --usuario HansNieto `
  --nombre "videria-video17"

Abre el repositorio privado en GitHub y añade a tu amigo como colaborador. Envíale la URL y el tutorial del revisor.

Recibir la revisión y renderizar

git -C "C:\Users\Hans\Documents\videria2.0\videria\videos\video17-proyecto" pull
python $VCUT studio --project "C:\Users\Hans\Documents\videria2.0\videria\videos\video17-proyecto"
python $VCUT render --project "C:\Users\Hans\Documents\videria2.0\videria\videos\video17-proyecto"
El MP4 final queda en videos\video17-proyecto\exports\.

Cuando actualicemos la app

La app y los proyectos son independientes. Actualiza primero el repositorio de Videria y luego reinstala sus skills.

cd C:\Users\Hans\Documents\videria2.0\videria
git status
git pull
.\instalar.ps1

Cierra y vuelve a abrir cualquier Studio que estuviera ejecutándose. El instalador crea un respaldo fechado de la versión anterior.

No ejecutes git pull si git status muestra cambios tuyos sin guardar. Primero haz commit o pide ayuda.

Reglas para mantener todo ordenado

ElementoRegla
OriginalesUna carpeta videos\video##; nunca se renombran tras procesar.
ProyectoLa carpeta hermana terminada en -proyecto.
GitHubUn repositorio privado por vídeo: videria-V###-tema.
RendersSiempre dentro de exports/; Git los ignora.
ZIP recibidosEliminar cuando la extracción haya sido verificada.
