TU MESA DE EDICIÓN

¿Qué video seguimos?

Abre una preedición, dale tu toque y guarda. Los proyectos están separados de la app.

Trabajen por turnos

Antes de editar: recibe los cambios. Al terminar: guarda con Ctrl+S y publica la revisión con GitHub Desktop. Hans renderiza el final en la computadora que tiene los originales.

Ver el flujo para los dos →

Agregar un proyecto existente

Selecciona la carpeta que contiene project.json, por ejemplo video17-proyecto. No la carpeta de grabaciones originales.

Descargar proyecto de GitHub

Para repositorios privados, primero acepta la invitación y autentícate en GitHub. Si la descarga falla, usa GitHub Desktop → Clone repository y luego Agregar carpeta.

Se guardará en . Nunca reemplazamos una carpeta existente.
